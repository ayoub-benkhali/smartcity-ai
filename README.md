# SmartCity AI | NYC Mobility Intelligence

An end-to-end Urban Mobility BI & AI Platform.

## Mission
Transform public NYC transport data into actionable
intelligence for mobility and road safety planning.

## Technology Stack
- Databricks: PySpark, Delta Lake, Machine Learning
- Microsoft Fabric: OneLake, Lakehouse, Data Warehouse
- Power BI: Data modeling, DAX, Interactive dashboards
- Python, SQL, Git & GitHub

## Main Features
1. Intelligent urban mobility dashboards
2. Taxi demand forecasting
3. Traffic slowdown detection
4. Historical traffic playback
5. Interactive what-if simulator

## Data
Official NYC Open Data and TLC datasets.
